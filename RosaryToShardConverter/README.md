# Rosary to Shards

Ever feel too rich in rosaries but constantly run out of shell shards during boss or gauntlet retries? <br/>
This mod lets you convert excess rosaries into shell shards so you can keep using your favorite tools without being forced to switch.

## Overview

This is a lightweight Hollow Knight: Silksong plugin that converts your rosaries into shell shards, useful for repeated boss or gauntlet attempts.

## Features

- Convert any amount of rosaries that you have into shell shards. (Will not give shards more than the pouch capacity)
- Set an amount in the config and anytime use Hotkeys (CTRL + Quote ' ).
- Auto-convert feature to convert any rosaries that you gain into shell shards.

<span style="color:red;">Warning: Remember to disable auto-convert before breaking your cocoon with rosaries.</span>
