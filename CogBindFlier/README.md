# Cogfly Companion (CogBud) 

Summon a Cogwork Flier companion upon completing a Bind, giving you a helpful buddy.

## Overview

This is a lightweight bepinEx plugin that summons a cogfly each time you bind, giving you a loyal companion without needing to equip the tool.


The idea behind this mod is simple: turning Bind into a way to summon a helpful companion, making combat and exploration feel more dynamic.

## Features

- Automatically throws a Cogwork Flier after every Bind.
- Works even if Cogwork Flier is not equipped or unlocked.

### Additional Features 

- Configurable Cogflies per Bind (up to 8 active companions).
- ALT + R hotkey to remove all active Cogflies and reset capacity.
- Optional infinite durability — your cog buddies won’t get destroyed after dealing hits.
