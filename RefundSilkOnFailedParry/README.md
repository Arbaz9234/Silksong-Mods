# Bind Auto Silk Skill

Automatically release a silk skill after a bind, with no silk cost.

## Overview

This is a lightweight BepInEx plugin that automatically releases a Silk Skill after completing a Bind.

In the early game, when your Silk spool is full, you can either Bind to heal or cast a Silk Skill twice — <br/>but with low mask count,
most players choose to heal.<br/>

This mod allows you to automatically release a Silk Skill after binding, letting you recover and attack in one smooth flow.

## Features

- Automatically releases a Silk Skill after completing a Bind.
- Select skill from bepinEx configuration menu (F1)
- Allows you to heal and immediately follow up with a Silk attack.
