# Always Hit Kratt (the Pervert)

Simple mod that lets you hit Kratt again on repeat encounters.

## Overview

This is a lightweight plugin that lets you hit Kratt every time. Shameless Kratt will spy on Hornet every time she enters Spa.

Remember: Cost of hitting Kratt is **10 rosaries**.
