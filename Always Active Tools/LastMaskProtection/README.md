# Last Mask Protection

V2 of the [AlwaysFracturedMask](../AlwaysFracturedMask) mod

## Overview

True Always Fractured Mask mod: Prevents the fractured mask from breaking, ensuring Hornet always survives with one mask.

## Features

- Your tools permanently have Fractured Mask equipped.
- Mask never breaks
- Prevent Death in Steel Soul mode too.
