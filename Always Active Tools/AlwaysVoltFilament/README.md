# Always have Volt Filament

Permanently equip Volt Filament, apply electrical damage to Silk Skills.

## Overview

This is a lightweight mod for Hollow Knight: Silksong that makes the Volt Filament effect permanent on your tools without explicitly equipping.

## Features

- Your tools permanently have Volt Filament
- No need to equip the tool, allowing you an extra tool slot for other tools.
- Increase damage of Silk Skills by 25%
- It also adds a few ticks of 5 damage depending on the skill
