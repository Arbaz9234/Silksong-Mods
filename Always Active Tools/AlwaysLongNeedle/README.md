# Always Longclaw

Permanently equip Longclaw, increasing attack range at all times.

## Overview

This mod is for Hollow Knight: Silksong, which makes the Longclaw effect permanent on your tools without explicitly equipping.

## Features

- Your tools permanently have Longclaw
- No need to equip the tool, allowing you an extra tool slot for other tools.
- Added configurable range scaling (Normal / 1.5x / 2x).
