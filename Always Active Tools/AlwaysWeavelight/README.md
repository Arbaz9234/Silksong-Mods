# Always have Weavelight

This mod permanently equips Weavelight, increasing both the speed and quantity of passive Silk regeneration from Silk Hearts.

## Overview

This mod is for Hollow Knight: Silksong, which makes the Weavelight effect permanent on your tools without explicitly equipping.

## Features

- Your tools permanently have Weavelight
- No need to equip the tool, allowing you an extra tool slot for other tools.
- Have passive silk regeneration. (Best for users preferring Beast Crest)
