# Always have Shell Satchel

Permanently equips Shell Satchel, increasing the maximum number of Red Tools you can carry and use at all times.

## Overview

This mod for Hollow Knight: Silksong makes the Shell Satchel effect permanently active. <br/>
In the base game, Shell Satchel is exclusive to Steel Soul mode only.

This mod allows you to enjoy its benefits in a normal playthrough.

## Features

- Permanently increases the maximum quantity of Red Tools
- Brings Steel Soul–exclusive functionality into regular gameplay
