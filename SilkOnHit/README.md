# Silk On Hit

Grants silk whenever the player takes damage.

## Overview

Silk On Hit is a lightweight Silksong mod that rewards aggressive and risky play by granting silk whenever the player takes damage.

## Features

- Gain silk whenever you take damage
- Works with all damage sources (enemies, hazards, etc.)
- Configurable silk amount via BepInEx

Perfect for players who want a more forgiving or experimental silk economy without changing core combat mechanics.
