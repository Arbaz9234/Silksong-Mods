# Disable Shaman Runes

Simple mod to disable Shaman Runes.

## Overview

This mod removes the visual rune effects created by the Shaman (Spell) Crest while keeping all gameplay mechanics fully intact.

If you like the Shamans Crest’s damage and effects but dislike the floating runes, spawn flashes, or zap tint visuals, this mod cleanly disables them without altering balance.
