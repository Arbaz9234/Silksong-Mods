# Act 3 Start Early - No Silk and Soul wish required

Simple mod to let you start Act 3 without needing to finish the Silk and Soul quest.

## Overview

This is a simple Hollow Knight Silksong plugin to let you start Act 3 early.
No need to complete the Silk and Soul quest.<br/>
The caretaker will be at the top of the Cradle.

You can play Needolin on GMS and get to Act 3 straight after the Lace 2 boss fight
