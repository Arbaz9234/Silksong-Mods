# 2x Poison Ticks and Damage with Poison Stacking

This mod increases poison ticks and poison damage increasing Pollip Pouch Poison effects with poison stacking support.

## Features

- Increase poison ticks. (1 = 2 ticks, 2 = 4 ticks)
- Set poison damage multiplier for increased damage of each poison tick.
- Enable/disable poison stacking.
- Configure from the bepinEx configuration manager (F1)

<br/>

<span style="color:yellow;">Recommended:</span> Use
[AlwaysPollipPouch](https://www.nexusmods.com/hollowknightsilksong/mods/848?tab=files)
with this mod (by [iDentityStar](https://www.nexusmods.com/profile/iDentityStar)). <br/>
<span style="color:red;">Warning:</span> When poison stacking is enabled, nail hits will also inflict poison, which is cool too. [Just like poison equipped]
